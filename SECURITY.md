# Security policy

Please report suspected vulnerabilities privately through GitHub's security-advisory reporting
channel when available. Do not open a public issue containing exploit details, credentials,
production identifiers or confidential evidence.

VulnEvidenceOps is an alpha reference library. Its local intake and exposure-context operations
have no network clients and do not operate scanners or intelligence feeds. It has no patching,
authentication, storage, scoring or production-enforcement capability. A security report should
distinguish a defect in the local evidence contract from an out-of-scope production-system claim.
