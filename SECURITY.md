# Security policy

Please report suspected vulnerabilities privately through GitHub's security-advisory reporting
channel when available. Do not open a public issue containing exploit details, credentials,
production identifiers or confidential evidence.

VulnEvidenceOps is a stable-reference library. Its local intake, exposure, portfolio,
signed-evidence and integration operations have no network clients and do not operate scanners,
intelligence feeds, key management or timestamp services. It has no private-key generation or
storage, patching, authentication, scoring, executive workflow or production-enforcement
capability. A security report should distinguish a defect in local signature, digest, Git-blob or
profile verification from an out-of-scope identity, authority, delivery, custody, compatibility or
production-system claim.
